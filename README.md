# red

`red` 是一个在终端中阅读 Markdown 的 TUI（文本用户界面）阅读器。它支持大纲、搜索、目录浏览、可折叠内容、语法高亮和文件实时重载；也可以把 stdin 中的 Markdown 渲染为 ANSI 文本输出。

## 构建与运行

本项目使用 Cargo 构建。开发环境中执行：

```bash
cargo build
cargo run -- README.md
```

`cargo run --` 后的参数会传给 `red`：

```text
red [OPTIONS] [FILE]
```

输入方式：

- `red path/to/file.md`：在 TUI 中打开文件。文件按 UTF-8 读取；文件路径不要求必须使用 `.md` 后缀。
- `red path/to/directory`：打开该目录的浏览器。
- `red`：浏览当前工作目录。
- `red -`：从 stdin 读取 Markdown，使用默认 `RenderStyle` 完整渲染后写到 stdout，不进入 TUI；不应用配置中的版式和折叠默认设置，`<details>` 内容按完整文档输出。此静态分支不启用鼠标捕获，也不加载图片。`-` 需要连接到非终端的 stdin，例如：

  ```bash
  cat README.md | cargo run -- -
  ```

  如果 `-` 的 stdin 仍是终端，程序会提示应改用文件路径。

目录浏览器只显示非隐藏的子目录以及 `.md`、`.markdown` 文件；子目录排在文件前面，并按名称排序。直接给出文件路径时则不受该扩展名筛选限制。

### 命令行选项

```text
--theme <THEME>     初始主题：dark、gruvbox、nord、dracula、catppuccin
--no-watch          禁用文件实时重载
```

主题默认是 `dark`。`--no-watch` 主要影响 TUI 中打开的文件；目录浏览和 stdin 静态输出本身没有文件监视。未知的主题名称不会作为有效主题使用，最终按默认 `dark` 处理；请使用上面列出的名称。

默认构建不包含原生图片依赖，图片栏使用 `PathOnly`。如需可选的 Kitty、Sixel 或 iTerm2 原生图片后端，可使用 `cargo run --features native-images -- README.md`；能力探测失败、没有像素尺寸、协议为 Halfblocks 或图片加载/编码失败时都会安全回退到 `PathOnly`。

### 颜色与 `NO_COLOR`

若程序启动时设置了**非空**的 `NO_COLOR` 环境变量，会按无颜色处理：TUI 使用终端默认颜色，stdin 静态输出不产生颜色设置序列；粗体、下划线等文本修饰仍可能保留：

```bash
NO_COLOR=1 cargo run -- README.md
cat README.md | NO_COLOR=1 cargo run -- -
```

程序启动时未设置 `NO_COLOR`，会根据终端能力使用 truecolor、256 色或 16 色降级显示。运行中仍可在设置面板切换主题；上述说明针对启动时的颜色处理，不表示整个生命周期始终强制锁定为无色。

## 阅读界面快捷键

在阅读模式下：

| 按键 | 操作 |
| --- | --- |
| `j` / `↓` | 向下滚动一行 |
| `k` / `↑` | 向上滚动一行 |
| `Ctrl+D` | 向下滚动半页 |
| `Ctrl+U` | 向上滚动半页 |
| `Space` / `PageDown` | 向下翻一页 |
| `PageUp` | 向上翻一页 |
| `g` / `Home` | 跳到开头 |
| `G` / `End` | 跳到末尾 |
| `/` | 输入搜索词 |
| `n` / `N` | 跳到下一个/上一个搜索命中（循环） |
| `t` | 打开大纲 |
| `s` | 打开设置 |
| `Ctrl+O` | 在全部收起和全部展开之间切换所有 `<details>` 块 |
| 鼠标滚轮 | 在阅读模式中上下滚动 |
| `Ctrl` + 鼠标左键 | 点击实际显示的图片 alt 或路径文字，打开右侧图片栏 |
| `q` / `Q`、`Ctrl+C` | 退出 |
| `Esc` | 图片栏打开时先关闭图片栏；否则通常退出，或从目录浏览器打开文件后返回目录浏览器 |

TUI 默认启用鼠标捕获，因此不保留终端原生拖拽选择。默认图片栏为 `PathOnly`：显示标题、原始路径和相对于 Markdown 文件目录解析后的路径，不加载图片或发送终端图片转义序列。启用 `native-images` 且探测到 Kitty、Sixel 或 iTerm2 后，Ctrl+左键才会读取并解码本地图片，在栏内绘制原生图片；任何探测、尺寸、解码或编码失败都会回退到 `PathOnly`。只有正文中实际显示的 alt/路径文字可点击，行内其他空白、折叠隐藏内容、状态栏和右栏不会命中。

`Ctrl+O` 会先完成尚未渲染的内容，再操作文档中的所有可折叠块。全部展开时按一次会全部收起，再按一次会全部展开；如果当前状态不一致，则按一次统一为全部展开。普通小写 `o` 没有任何操作，不会切换折叠块。

鼠标修饰键只接受 crossterm 报告的 `CONTROL` + 左键；macOS 终端可能拦截 Control-click，Command、Option 等修饰键不会替代 Ctrl，遇到拦截时请使用键盘滚动或换用终端设置。

## 大纲

按 `t` 进入大纲侧栏：

- `j` / `↓`、`k` / `↑`：选择标题。
- `g` / `Home`：跳到第一项。
- `G` / `End`：跳到最后一项。
- `Enter`：跳到选中标题并返回阅读模式。
- `Esc` 或 `t`：关闭大纲并返回阅读模式。
- `q` / `Q`：退出。

文档没有标题时，按 `t` 不会打开侧栏，而是在状态栏提示没有大纲。

## 搜索

在阅读模式按 `/`，输入搜索词后按 `Enter` 执行：

- 搜索匹配使用 Unicode 小写转换，因此匹配本身不区分大小写；正文高亮实现使用 ASCII 小写转换，非 ASCII 字符的大小写高亮可能有限制。
- `n` 跳到下一个命中，`N` 跳到上一个命中，命中会循环。
- `Backspace` 删除输入末尾字符，`Ctrl+U` 清空输入，`Esc` 取消本次输入。
- 空搜索词会清除当前搜索；没有命中时状态栏显示提示。

搜索按渲染后的行文本进行，因此会随终端宽度、换行和版式设置变化而重新计算。

## 设置

在阅读模式按 `s` 打开设置侧栏，使用 `j` / `k` 选择，使用 `←` / `→` 或 `Enter` 修改；按 `s` 或 `Esc` 返回阅读。设置变更会尝试写入用户配置文件，正常情况下会持久化；写入失败时静默忽略。

可调整项目：

- **主题**：在 `dark`、`gruvbox`、`nord`、`dracula`、`catppuccin` 之间循环。
- **安全区**：左右内容边距。方向键在 `0`、`1`、`2` 列之间循环；按 `Enter` 进入数字输入，可输入 `0`–`6` 列，再按 `Enter` 确认，`Esc` 取消。
- **行距**：紧凑或宽松。
- **段距**：紧凑、标准或宽松。
- **折叠默认**：普通文档及当前已渲染内容中的 `<details>` 块默认展开或收起；大文件懒渲染的后续块不保证完全按该默认状态生效。
- **恢复默认**：恢复 `dark` 主题、安全区 2 列、紧凑行距、标准段距和默认展开。

设置侧栏中的 `q` / `Q` 也会退出程序。

## 目录浏览

启动时不给参数、给出目录，或从目录中打开文件后按 `Esc`，会进入目录浏览器：

| 按键 | 操作 |
| --- | --- |
| `j` / `↓` | 选择下一项 |
| `k` / `↑` | 选择上一项 |
| `g` / `Home` | 选择第一项 |
| `G` / `End` | 选择最后一项 |
| `Enter` / `→` / `l` | 进入目录或打开选中的 Markdown 文件 |
| `Esc` / `←` / `h` | 返回上级目录 |
| `r` | 重新扫描当前目录 |
| `q` / `Q` | 退出 |

目录中会显示 `..` 上级入口（根目录没有上级入口）、子目录和 Markdown 文件；隐藏项及其他扩展名文件不会列出。打开文件后，`Esc` 返回启动该文件的目录浏览器。

## 配置

配置文件路径为：

1. `$XDG_CONFIG_HOME/red/config.toml`（设置了 `XDG_CONFIG_HOME` 时）；
2. 否则为 `$HOME/.config/red/config.toml`。

如果两个环境变量都不可用，则没有可用的配置路径，设置仍可在当前运行中使用但不会持久化。保存设置时会尝试创建配置目录和文件，正常情况下会持久化；写入失败时静默忽略。文件不存在或无法读取时按默认值启动；可读取的配置文件按字段解析，非法字段和未知字段忽略，其他合法字段继续生效。

支持的字段及默认值：

| 字段 | 类型/范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `theme` | 字符串：`dark`、`gruvbox`、`nord`、`dracula`、`catppuccin` | `"dark"` | 初始主题 |
| `safe_zone` | 整数，`0`–`6` | `2` | 正文左右安全区列数 |
| `line_gap` | 整数，`0` 或 `1` | `0` | 正文折行间是否插入空行 |
| `para_gap` | 整数，`0`–`2` | `1` | Markdown 块之间的空行数 |
| `fold_default` | 布尔值 `true` / `false` | `false` | 普通文档和已渲染内容中的 `<details>` 默认是否收起 |

示例：

```toml
theme = "nord"
safe_zone = 2
line_gap = 0
para_gap = 1
fold_default = false
```

优先级为“内置默认值 < 配置文件 < 命令行”：有效的 `--theme` 覆盖配置文件中的 `theme`；`--no-watch` 是只存在于命令行的开关，没有对应配置字段。进入程序后的设置面板修改会立即覆盖当前值，并尝试将所有设置字段保存回配置文件，正常情况下会持久化；写入失败时静默忽略。

配置中的数值会在启动时限制到实现支持的范围；无法解析的主题、数值或布尔值不会生效，能解析但超出范围的数值会被钳制。配置解析是按 `key = value` 逐字段进行的简单格式；单个字段非法时忽略该字段，其他合法字段继续生效。主题值可以带引号；设置面板保存时会按上例输出。

## Markdown 支持

Markdown 使用 CommonMark 风格解析，并启用了表格、任务列表和删除线扩展。当前渲染器支持：

- 1–6 级标题（同时生成大纲）。
- 段落、自动按终端宽度折行、强调、加粗、删除线、行内代码。
- 有序列表、无序列表、嵌套列表、任务列表。
- 引用块、分割线和表格（包含表头、对齐和必要时的单元格折行）。
- 围栏代码块和缩进代码块。带语言标记的代码块使用 `syntect` 语法高亮，未知语言按纯文本处理。
- 链接和图片的文本。图片正文始终显示 alt 和路径文字；只有本地图片路径可以通过阅读模式中的 `Ctrl` + 鼠标左键打开右侧栏。相对路径相对于 Markdown 文件所在目录；`http`、`https`、`data`、`file`、`ftp` 等 URI 不加载、不联网，图片本体默认不显示。使用 `--features native-images` 且终端探测到 Kitty、Sixel 或 iTerm2 时，右侧栏才会尝试绘制原生图片。
- `<details>` / `<summary>` 折叠块：展开时显示块内容，收起时显示带标题和行数的摘要；可用设置指定默认状态，主要适用于普通文档和已渲染内容，也可用 `Ctrl+O` 全部切换。

其他未被专门处理的 HTML 不提供浏览器式布局或交互。

## 实时重载与大文件

直接阅读文件时，默认启用实时重载。文件发生变化后会重新读取、重新渲染，并尽量保持当前滚动位置；若当前有搜索词，会刷新搜索命中。`--no-watch` 可关闭此行为。stdin 输入和目录浏览不监视文件，目录中的文件在打开后才按当前开关决定是否监视。

窗口宽度改变时，正文会按新宽度重新渲染；安全区、行距和段距等版式设置也会触发重新渲染。图片栏打开或关闭时，正文会使用扣除右栏后的实际宽度重新折行，同时保留折叠和搜索状态。

`--no-watch` 只关闭文件变化监视，不会丢失 Markdown 文件路径；因此本地图片的相对路径仍相对于该 Markdown 文件所在目录解析。图片栏重载后若引用仍存在会更新元数据，失效引用会清理并关闭面板。

源文件大于 1 MiB 时启用懒渲染：程序先渲染首个块，阅读时按视口需要继续渲染，大纲跳转会先渲染目标所在块；大文件预扫描大纲只识别 ATX 标题（`#` 至 `######`），其他形式（如 setext 标题）可能不在预扫描结果中；跳到末尾或执行 `Ctrl+O` 时会完成剩余内容的渲染。懒渲染按源文分块，跨块 Markdown 结构（如大型 `<details>`、围栏代码块、列表）可能受分块边界影响，最终显示结果可能与一次性渲染不同。

## 开发验证

在仓库根目录运行：

```bash
cargo fmt --check
cargo check
cargo test
cargo build
```

其中 `cargo check` 用于快速检查默认构建，`cargo test` 运行项目测试，`cargo build` 验证默认产物。可选后端还应运行 `cargo check --features native-images` 和 `cargo test --features native-images`。项目当前没有额外的安装步骤或独立的运行时服务。
